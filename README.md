<h3><a href="https://github.com/abdulwasay4585/mini-cuBLAS">Mini cuBLAS</a></h3>
<p><strong>Make custom CUDA computation accessible through Python.</strong></p>
<p>Built a GPU linear algebra library that connects custom CUDA kernels to Python bindings and a Streamlit visualizer, making the implementation and its performance easier to explore.</p>

<li><strong>Made results inspectable:</strong> included numerical checks and GFLOPS benchmarking.</li>
</ul>
